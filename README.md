# Teslo API

1. ```pnpm install```
2. Usar ```.env.template``` como base para crear el archivo ```.env```
3. Cambiar variables de entorno a las equivalentes
4. Levantar base de datos:
```
docker-compose up -d
```
5. Levantar: ```pnpm run start:dev```
